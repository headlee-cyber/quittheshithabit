# マクロ管理（筋トレ用食事管理 PWA・個人用）

PFC・カロリーの記録、写真からのAI推定、目標値の自動計算、食品データベース、体重推移グラフを備えた個人用 Web アプリです。
スマホのホーム画面に追加してアプリのように使えます（PWA）。

公開先: https://headlee-cyber.github.io/quittheshithabit/ （`main` へ push すると GitHub Actions で自動デプロイ）

## 機能

| タブ | 内容 |
| --- | --- |
| 今日 | 写真からAIで推定して記録 / 食品×グラム数 / PFC 手入力。目標に対する進捗バー |
| 体重 | 体重記録、推移グラフ（暦日ベースの7日平均）。最新日の体重は目標計算に自動反映 |
| 食品 | 自分用食品の登録・編集（100g あたり）、組み込み食品のコピー |
| 設定 | プロフィールと目標値、APIキー、バックアップの書き出し・復元 |

## 写真からのAI推定

1. 「写真を撮る / 選ぶ」で撮影（任意で「ご飯大盛り」などの補足メモ）
2. Claude（`claude-opus-5-5`）が品目ごとに重量・kcal・PFC を推定
3. 量や数値を確認・修正し、不要な品目のチェックを外して記録

- 推定値は目安です。見えない油・ソースや量の見積もりで、2〜3割程度ずれることがあります。
- 画像は長辺 1568px の JPEG に縮小して送信します。
- 1回ごとのトークン数と料金の目安を画面に表示します。
- モデルが応答を断った場合は、サーバー側フォールバック（`fallbacks: "default"`）で別モデルが応答します。

### APIキーについて

個人利用のため、サーバーを置かずにブラウザから Anthropic API を直接呼び出しています。

- キーは「設定」タブで入力し、**その端末のブラウザ内（localStorage）にだけ**保存されます。コードやリポジトリには含まれません。
- 端末を他人に使われた場合などにキーが漏れる可能性はゼロではないため、[Anthropic Console](https://console.anthropic.com) で**月の利用上限額を設定**してください。
- 複数人で使う形にする場合は、キーをサーバー側に置く構成に変更が必要です。

## データとバックアップ

データはすべて端末のブラウザ内に保存されます（サーバーなし・同期なし）。
ブラウザのデータを消去すると記録も消えるため、「設定 > バックアップ > 書き出す」で定期的に JSON を保存してください。
iPhone では Safari の「ホーム画面に追加」から使うと、データが自動削除されにくくなります。

## 目標値の計算方法

- 基礎代謝: Mifflin-St Jeor 式（男性 `10W + 6.25H − 5A + 5`、女性 `… − 161`）
- 消費カロリー = 基礎代謝 × 活動係数
- 目標カロリー = 消費カロリー + 増減（初期値: 増量 +300 / 維持 0 / 減量 −500 kcal）
- P = 体重 × g/kg（初期値 2.0）、F = 目標カロリー × 脂質割合（初期値 25%）÷ 9、C = 残り ÷ 4

組み込み食品は日本食品標準成分表(八訂)を参考にした目安値です。

# 音声 To Do（声で一日の計画を立てる・個人用）

朝、その日やりたいことを話すと、AI がタスクを取り出し、Google カレンダーの予定を避けて時間割を組みます。
確認した時間割は Google カレンダーに登録できます。マクロ管理とはデータも画面も独立した別ページです。

公開先: https://headlee-cyber.github.io/quittheshithabit/todo/ （ローカルでは `npm run dev` → `/quittheshithabit/todo/`）

## 流れ（「今日の計画」タブ）

1. マイクを押して、やりたいことを思いつくまま話す（文字入力・修正も可）
2. 「AI に計画を立ててもらう」を押す。Claude がタスクと所要時間を見積もり、時間割を作る
   - 入力: 発話、リストの未完了タスク、今日のカレンダーの予定、設定した時間帯と好み
   - 出力: 時間割、今日は入れなかったものとその理由、考え方のコメント
3. 時間割を確認する。不要な枠は × で外す。「修正を頼む」で「ジムは夜にして」のように直せる
4. 「Google カレンダーに登録」を押すと、メインのカレンダーに予定として書き込む
5. 終わったタスクは時間割のチェックボックスで完了にする

- 抽出されたタスクは「リスト」タブにも今日が期限のタスクとして追加されます。
- カレンダーへの書き込みは、ボタンを押したときだけ行います。修正で時刻が変わった枠は、次の登録時に古い予定を削除して入れ直します。
- AI の出力は検証し、既存の予定や他の枠と重なる枠には「重複」と表示します。
- 計画は当日分だけ保持し、日付が変わると入力画面に戻ります。

## 初期設定（「設定」タブ）

### 1. Anthropic APIキー

マクロ管理アプリと同じキーを共用します（登録済みならそのまま使えます）。注意点は上の「APIキーについて」と同じです。
計画の作成 1 回あたりの料金の目安を画面に表示します。

### 2. Google カレンダー（任意）

未設定でも計画は作れますが、既存の予定は考慮されず、カレンダーへの登録もできません。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成し、「Google Calendar API」を有効にする
2. 「OAuth 同意画面」を作成する（ユーザーの種類: 外部、公開ステータス: テスト）。テストユーザーに自分の Google アカウントを追加する
3. 「認証情報」→「OAuth クライアント ID」を作成する（種類: ウェブ アプリケーション）。
   「承認済みの JavaScript 生成元」に `https://headlee-cyber.github.io` を追加する（ローカルで試す場合は `http://localhost:5173` も）
4. 発行されたクライアント ID を「設定」タブに貼り付ける

- 初回の接続時に「このアプリは Google で確認されていません」と表示されます。自分で作ったアプリなので「詳細」から続行します。
- 要求する権限は、予定の閲覧・編集（`calendar.events`）とカレンダー一覧の閲覧（`calendar.calendarlist.readonly`）です。
- アクセストークンは約 1 時間で失効し、タブを閉じると消えます。その場合はもう一度「接続」を押します。
- 予定は Google カレンダーで表示をオンにしているすべてのカレンダーから読み込みます。辞退した予定と「予定なし」扱いの予定は除きます。

### Apple 純正カレンダーについて

Apple のカレンダー（iCloud）には Web アプリから使える API がないため、直接の連携はしていません。

- **書き込み**: iPhone / Mac の「設定 > カレンダー > アカウント」に Google アカウントを追加すると、このアプリが登録した予定は純正カレンダーアプリにも表示されます。
- **読み込み**: iCloud カレンダーにだけ入っている予定は、このアプリからは見えません。予定を考慮させるには Google カレンダー側に置く必要があります。

## リストの音声操作（「リスト」タブ）

AI を使わないルールベースの操作です。マイクを押して話します。語尾に操作の言葉がなければ「追加」として扱います。

| 操作 | 話し方の例 |
| --- | --- |
| 追加 | 「牛乳を買う」「明日までにレポートを出すを追加」 |
| 期限 | 今日 / 明日 / 明後日 / 3日後 / 金曜 / 来週の月曜 / 11月20日 |
| 完了 | 「牛乳を完了」「洗濯終わった」「2番を完了」 |
| 未完了に戻す | 「牛乳を未完了に戻して」 |
| 削除 | 「牛乳を削除」「1番を消して」「完了済みを全部削除」 |
| 取り消し | 「元に戻して」「取り消し」（直前の1操作のみ） |

- タスク名はあいまい一致で探します（部分一致、ひらがな・カタカナの違いは吸収）。漢字とかなの違いなど、認識結果の表記が大きく異なると一致しません。その場合は画面の番号で指定してください。
- 「消す」「完了」などで終わるタスクを追加するときは、「部屋の電気を消すを追加」のように最後に「追加」を付けます。
- 「話し方の例」内の「止めるまで連続で聞き取る」をオンにすると、1回の発話ごとに止まらず聞き取りを続けます。
- 手入力欄からも追加できます（常に追加として扱い、期限の表現だけ解釈します）。

## 制約

- 音声認識はブラウザの Web Speech API を使います。Chrome / Edge / Safari が対象で、Firefox では手入力のみになります。
- Chrome などでは音声がブラウザ提供元の認識サーバーに送られるため、音声入力にはネット接続が必要です。
- 「リスト」タブの発話の解釈はルールベース（`src/todo/parse.ts`）です。想定外の言い回しは「追加」として扱われます。
- 計画の作成では、発話の文字起こし・タスク名・カレンダーの予定名が Anthropic API に送信されます。
- AI の所要時間の見積もりや優先順位は目安です。登録前に時間割を確認してください。
- タスクと計画は端末のブラウザ内（localStorage）にのみ保存されます。端末間の同期はありません。
